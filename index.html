Vue 3 错误监控：接入与验证

Vue 3 初始化传入 createApp() 创建的应用实例，而不是 Vue 构造器。点击「Vue 组件异常」后，在观察窗选择对应记录，展开报告 JSON。

npm install @mitojs/browser@4.0.0 @mitojs/vue@4.0.0
import { createApp } from 'vue'
import { init } from '@mitojs/browser'
import { vuePlugin } from '@mitojs/vue'
import App from './App.vue'

const app = createApp(App)
init({ vue: app, dsn: '/reports' }, [vuePlugin])
app.mount('#app')

/reports 是示例接收地址，接入项目时请替换为自己的监控接收端。本 Demo 的请求和上报在浏览器本地拦截，观察窗展示 SDK 实际生成的报告。
